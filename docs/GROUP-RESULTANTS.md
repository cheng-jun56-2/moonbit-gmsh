# 按物理组交付标量法向合量

已有带字段MSH时，按明确的二维物理组和原字段段索引，一次保存每组子网格、标量法向合量`∫s n dA`、原件/请求及SHA清单。该流程组合已有MoonBit选择、编码和积分方法，不新增数学规则或改变核心API；Node仅处理文件、选项和调用顺序。它与只计算单个已选面文件的旧CLI以及固定自建输入的旧示例分别可用。

```sh
moon build --target js --release
node examples/group_resultants/run.mjs examples/group_resultants/source.msh examples/group_resultants/options.json NEW_DIRECTORY
```

接收自己的文件时，将前两个路径替换为已有MSH与UTF-8 JSON请求文件：

```json
{"field_index":1,"groups":[55,44],"max_samples":12}
```

`field_index`是当前原件的零基段索引，必须明确提供，不按字段名或时间选段。`groups`按顺序列出1..16个互不重复的正32位物理组ID，维度固定为2。每组必须包含可供原标量法向接口计算的面；没有面、缺少选定节点/单元数据、非标量或命名插值方案等仍报错。Tri3/Tri6/Quad4/Quad8/Quad9范围、完整节点与固定求积规则见[NORMAL-FIELD.md](NORMAL-FIELD.md)。有体网格时只选择已有显式二维单元，不自动提取外皮，也不把体字段当成面数据。

`max_samples`默认1000000，范围0..9000000，分别适用于每组；它是计算额度，不是误差容限。可选布尔`drop_unknown`默认为false，未知段必须明确丢弃后才能做选择；`allow_loss`默认false，只授权原编码器报告的已知表达损失，不能代替丢弃未知段。未知选项、错误类型及非法UTF-8会拒绝，合法Unicode保持。沿用现有JSON序列化：没有时间头时不含`time`属性，没有方案/partition时也省略相应可选属性，不编造时间0。

目录必须不存在。保存内容：

- `original.msh`和`request.json`是输入文件的完整原字节。
- `group-I.msh`按请求位置编号，使用原版本、小端二进制、8字节size_t。原tag、有序节点角色、分类/参数、实体/名称和所有字段段的顺序保留；沿用subset语义，删除未使用节点/字段行，仅更新各段条数。孤立节点、其他组的字段值仍可在归档原件中核对。元数据实体/名称不裁剪，不能仅凭名称目录断言面实际存在。
- `group-I-result.json`保存物理组/维度/原段索引、源与接收网格的帧目录项、原标量法向接口完整结果。计算输入就是将保存的那份二进制MSH字节，经过相同解码入口。
- `manifest.json`记录组顺序、文件名、明确选项、源路径，以及其他所有文件的SHA256和字节数；清单不包含自身哈希。JSON/MSH均为已有格式，没有引入新的网格格式。

所有组的选择、编码和计算成功后才创建目录。较晚一组的覆盖或预算错误也不会留下较早组的半份交付。已有目录不覆盖；文件以独占创建方式写入。写盘阶段的IO失败可能留下部分目录，不能把它当作原子发布。输入上限128MiB、选项8000000字节；所有组网格/结果载荷合计上限128MiB，达到上限拒绝且不建目录。该流程全部驻内存，不宣称流式、内存或速度优化。

多个物理组可以包含同一单元。每组独立保留贡献，**不提供跨组总和**；否则重叠面会被误计。所存节点绕向决定法向符号，流程不修复外向，不推定压力正负、单位、坐标基或来源真实性。固定求积的数值估计不是误差/几何有效性证书。

自建手写夹具中，A面面积2且朝+z，B面面积3且朝+x，C面与A反向；节点标量为`1+x`。组55含A/C，合量[0,0,0]、面积4；组44按源单元顺序含B/A，合量约[3,0,10/3]、面积5。A同时属于两个组，线单元也有编号44但不属于二维请求。原件另有孤立节点、九分量字段和同名同时间的稀疏段，用于核对完整交付而非仅看总量。

```sh
moon run examples/group_resultants --target js
moon run examples/group_resultants --target wasm-gc
```

公共包接收例输出完整子网格见证和原接口结果；文件入口接受真实路径。两者都是自编集成验证，不代表外部客户采用。开发核验`tools/verify-group-resultants.py`使用手写原件、独立struct/ASCII读取和上述解析期望，消费清单列出的全部实际文件；不拿产品dump或自编码回环当预期。旧数值参考门保持。
